PLP Image Column Split — แก้ปัญหา Schema และ Cache ระดับ Root Cause
Dedicated Column Isolation · Context Separation · Production Redis Invalidation · Zero Incident
⚠️ The Incident & Root CauseANALYSIS
  • The Symptom: แอดมินเปลี่ยนรูปสินค้าเฉพาะหน้า PLP แต่ทำให้รูปชิป FamilyStripe ด้านบนพังทั้ง LOB
  • Root Cause Tracing: พบว่า lobProducts() (แถบชิปบน) และ products() (ตารางสินค้า) อ่านฟิลด์เดียวกัน pd_stripe_image_plp ภายใต้ context=plp
  • The Trap: การคิดว่าฟิลด์เดิมแยกกันแล้ว โดยไม่ได้ Trace หาจุดเรียกอ่าน (Read Call-sites) ทั้งหมดในโค้ด
✅ The Architecture SolutionDELIVERED
  • Database Migration: สร้างคอลัมน์ใหม่ pd_plp_image แยกขาดจาก FamilyStripe 100%
  • Model & Context: เพิ่ม Product::plpRowImageUrl() และบริบทใหม่ context=plp_row
  • Production Cache Bust: บัสแคช Redis บนเซิร์ฟเวอร์จริง (แยกคนละ Instance กับ Local)
  • Precedent Pattern: ใช้มาตรฐานเดียวกับ pd_plp_sort_order ที่แยกก่อนหน้านี้
🛡️ ยืนยันผลลัพธ์ผ่าน HTTP End-to-End Test ทั้งสอง Endpoint ก่อน Deploy
